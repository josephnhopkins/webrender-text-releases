# Webrender Text — releases

Downloads for **Webrender Text**, a deliberately lo-fi notepad for your computer — no tabs, no
formatting, just text, with word wrap and zoom — from Nextwaveweb Ltd. It needs no account: it
opens and saves files on your computer, and it opens and saves notes in your Webrender Library
only when you ask it to. What it is, the download links and what to expect on first run are on
its page:

**https://nextwaveweb.co.uk/products/webrender-text**

This repository holds no source code — only the released builds: one GitHub Release per
version, with the downloads as its assets. Every download carries a README (what you need,
saving and organizing notes, connecting to your Library, the first-run warning, removal) and a
`THIRD-PARTY-NOTICES.txt` listing the open-source components it is built from — beside the
program in the Windows zip and in the folder the Windows installer installs to.

Windows is at 0.1.0. macOS and Linux follow.
